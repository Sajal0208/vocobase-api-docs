## What you can build

| | |
|---|---|
| **Agents** | Create agents, give them a [knowledge base](/knowledge-base), bias transcription with [dictionaries](/dictionaries), and template prompts with [pre-call variables](/pre-call-variables). |
| **Tools** | Let the agent call your own HTTP endpoints with [custom functions](/custom-functions), or fetch and push data automatically with [lifecycle hooks](/lifecycle-hooks). |
| **Outbound** | Dial through [your own telephony provider](/telephony/byop-setup), one call at a time or as a [campaign](/campaigns). |
| **Inbound** | Point a number at an agent and [route calls before they are answered](/inbound-routing-policies). |
| **In the browser** | Talk to an agent over WebRTC with no phone call at all — see [web voice](/web-voice-testing). |
| **Results** | Pull structured fields out of finished calls with [post-call extraction](/post-call-extraction), delivered on [webhooks](/webhooks/payloads). |
| **Live calls** | [Transfer to a human](/call-transfer) mid-conversation, or [detect voicemail and screeners](/voicemail-and-screener-detection). |
